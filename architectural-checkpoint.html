4. Visibility Model

✓
Privacy Defaults — FIXED

Critical fix applied: JournalEntry visibility default changed from PUBLIC to PRIVATE.

visibility @default(PUBLIC)
visibility @default(PRIVATE)

All content now defaults to PRIVATE. Publishing workflow: Create → Draft → Review → Explicitly publish. Nothing becomes public without intentional action.

✓
API Enforcement Verified

All public API routes filter by status: PUBLISHED AND visibility: PUBLIC for unauthenticated requests. Filtering applied at query level (not post-filter). Consistent across:

  • /api/projects (list & detail)
  • /api/articles (list & detail)
  • /api/journal (list & detail)
  • /api/search (global search)
  • /api/media (asset access)

5. Authentication Model

✓
NextAuth.js v5 — Single Owner

Credentials provider with bcrypt password hashing, JWT sessions, middleware protection on /admin routes. No multi-user complexity — one owner, public readers.

8. Publishing Workflow

✓
Explicit Publish Required

Content Lifecycle:

CREATE → DRAFT + PRIVATE (default)
       ↓
    REVIEW (authenticated only)
       ↓
    PUBLISH (explicit action)
       ↓
    PUBLIC (visible to world)

POST endpoints create with status: DRAFT, visibility: PRIVATE by default. PUT endpoints allow explicit status/visibility changes. publishedAt timestamp set automatically on first publish.
