Privacy Guardrails

Strict default protections enforced at data access layer.

🔒
Default-Private States

All records default strictly to status: DRAFT and visibility: PRIVATE.

🛡️
Query-Level Filtering

Unauthenticated visitors only retrieve status: PUBLISHED & visibility: PUBLIC via API & search.

☁️
Object-Level S3 Isolation

Private media signed URLs expire after 1 hour; no plain public web uploads on the node filesystem.
